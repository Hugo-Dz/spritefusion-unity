# Sprite Fusion

Generate pixel-art sprites and animations from the Unity editor.

## Connect

Open `Window > Sprite Fusion`, click `Connect`, and approve the device code in your browser.

## Generate

Enter a prompt, choose a size from `16x16` to `128x128`, and click `Generate`. The generated images are saved under `Assets/SpriteFusion/Generated`.

## Animate

After generating an image, select it as the source image, enter an animation prompt, and click `Animate`.
